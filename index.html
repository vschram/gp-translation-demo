Gaussian Processes: Predicting with Uncertainty

How much will additional training data improve the performance of machine learning models, and how certain can we be?

Try it

  • Each tab reproduces one step of the lesson. Work through them in order, then experiment.
  • Hover to see the prediction at any size. With one measurement, the tooltip shows the rule: expected + similarity × surprise.
  • In tab 6, click the chart to run an experiment at that dataset size: the real measured score appears. Double-click a measurement to remove it.
  • In Quiz 2, drag the red point up or down to ask "what if the 10k run had scored this?"
Data: real measurements of a translation model trained on Indonesian→English sentence pairs (source). Prior: expected 50 at 10k pairs and 56 at 100k, ± 5 (one standard deviation). Cost: assumed to grow in proportion to the number of sentence pairs, so ten times more data costs ten times more.
